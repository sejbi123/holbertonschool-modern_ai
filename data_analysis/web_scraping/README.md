# Web Scraping

## Description

This project focuses on collecting data from web pages using Python. It covers fetching HTML content, extracting structured information, and handling pagination.

## Tasks

- **0-fetch_html.py** — Fetches HTML content from a URL using the `requests` library.
- **1-scrape_basic.py** — Extracts quotes, authors, and tags from a web page using BeautifulSoup.
- **2-scrape_paginated.py** — Collects quotes from multiple pages by following pagination links.

## Technologies

- Python 3
- Requests
- BeautifulSoup
- HTML parsing
- URL handling and pagination

## Usage

Run each script or import its functions from Python. The scraping tasks require the appropriate Python dependencies to be installed.
