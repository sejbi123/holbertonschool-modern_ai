# Holberton School — Modern AI

## Description

This repository contains projects and exercises completed as part of the Holberton School Machine Learning and Modern AI learning journey.

The projects focus on Python programming, data analysis, data collection, and machine learning concepts.

## Repository Structure

- `data_analysis/web_scraping/` — Exercises focused on fetching HTML content, extracting information from web pages, and handling pagination.

## Technologies

- Python 3
- Git and GitHub
- Data analysis and web scraping libraries
